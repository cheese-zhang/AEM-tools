# Changelog

Every release documents user-visible additions under **New Features**.

## 0.8.0

### New Features

- Added Ctrl+Click navigation from custom Granite render-condition resource
  types to ordinary Java classes implementing `RenderCondition`.
- Added multi-target navigation when both a repository resource and Java
  implementation match the same resource type.
- Added Java implementation details to hover documentation and gutter actions.

## 0.7.9

### New Features

- Added a detailed feature overview to the IntelliJ plugin information page.
- Added structured New Features notes to plugin updates and GitHub releases.

### Improvements

- Changed the displayed plugin author name to **Cheese**.
- Removed repository links from the plugin overview text.

## 0.7.8

### New Features

- Added Ctrl+Click navigation from JavaBean getters to HTL usages.
- Added local navigation for non-component `/apps` and `/libs` script resources.
- Added **Open Resource** gutter actions for render conditions and similar resources.

## 0.7.7

### New Features

- Added plugin author metadata and GitHub project information.
- Added an AEM Author setup prompt to the AEM Toolkit tool window.
- Added author and project actions to AEM Toolkit settings.
